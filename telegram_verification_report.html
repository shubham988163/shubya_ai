How the Integration Works

1. Scanner Detects Signal

When the F&O scanner at /fno identifies a BUY or WATCH setup, the JavaScript code receives the result

2. JavaScript Alert Triggered

The checkAndAlert() function runs and now calls sendTelegramAlert(item, type)

3. API Request Sent

POST /api/telegram-alert { "title": "⚡ F&O BUY: RELIANCE", "message": "₹1,285.70 | Score: 75/100 · A · breakout above opening range" }

4. Server Processes Alert

Dashboard receives request and calls notify(title, message)

5. Telegram Message Sent

Telegram API receives the message and sends it to your bot chat
